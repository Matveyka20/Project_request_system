# Прототипы Request System

Актуальный редактируемый макет: [RequestSystem в Figma](https://www.figma.com/design/l6wkwHBoNsNgTN9n0LkvPD/RequestSystem).

В файле представлены следующие экраны:

- Вход (`sign-in`)
- Главный экран со списком заявок (`request-list`)
- Создание заявки (`request-create`)
- Редактирование заявки (`request-edit`)

Текст, пользователи, заявки, вложения и другие значения в прототипах являются демонстрационными. Их нельзя считать реальными данными.

## Экспорты

PNG-экспорты экранов входа и списка заявок находятся в `assets/sign-in.png` и `assets/request-list.png`. Экспорты создания и редактирования заявки пока не добавлены: Figma MCP достиг лимита вызовов до завершения экспорта. Не заменяйте их изображениями-заглушками.

Статус незавершённых экранов:

- Создание заявки (`8:12`): экспорт PNG запрошен, но Figma MCP отклонил запрос из-за лимита вызовов Starter plan.
- Редактирование заявки (`26:12`): экспорт PNG запрошен, но Figma MCP отклонил запрос из-за лимита вызовов Starter plan.
- Карточка подробностей: экран был удалён из макета; пользователь подтвердил восстановление. Восстановление и экспорт не выполнены: запись в Figma недоступна в текущей сессии, а Figma MCP ранее сообщил о лимите Starter plan.

Не считайте эти экраны восстановленными и не добавляйте изображения-заглушки.

Чтобы вручную экспортировать экраны создания и редактирования или получить PDF:

1. Откройте макет в Figma и выделите верхнеуровневый фрейм нужного экрана.
2. В панели **Export** добавьте формат `PNG` или `PDF` и нажмите **Export**.
3. Сохраните файлы в `docs/prototypes/assets/`, используя имена `request-create.png` и `request-edit.png` (или соответствующие расширения `.pdf`).

После восстановления карточки экспортируйте её в `docs/prototypes/assets/request-details.png` (или `.pdf`). Экраны создания, редактирования и карточка остаются незавершёнными до фактического экспорта из Figma. Храните в этой папке только экспортированные из Figma файлы; при обновлении макетов заменяйте экспорты соответствующими актуальными файлами.
