# Система обработки заявок

Учебный проект для централизованной регистрации, распределения, выполнения и контроля заявок на работы или услуги.

## Назначение

Система помогает заявителям отслеживать обращения, операторам — проверять и назначать заявки, исполнителям — фиксировать ход работы и результат, а контролёрам — принимать результат или возвращать его на доработку. История изменений и уведомления делают процесс обработки прозрачным для его участников.

## Основные функции

- создание заявок с описанием и категорией, просмотр статуса и истории;
- проверка заявок, запрос уточнений и назначение исполнителей;
- фиксация хода выполнения и передача результата на проверку;
- приёмка результата или возврат на доработку;
- уведомления участников и разграничение доступа по ролям.

Подробные требования, роли, сущности предметной области и критерии приёмки описаны в [техническом задании](docs/TZ.md).

## Разработка и проверка

Создайте и активируйте виртуальное окружение, затем установите проект:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
```

Запустить приложение и тесты можно командами:

```powershell
python -m request_system
python -m unittest discover -s tests -v
```
